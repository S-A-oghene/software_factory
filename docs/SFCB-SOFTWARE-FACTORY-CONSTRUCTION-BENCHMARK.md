# SFCB — Software Factory Construction Benchmark

## Objective

Test whether Software_Factory can construct systems, not just patches.

## Challenge levels

### Level 1 — product generation

Generate complete applications from specifications with realistic business workflows.

### Level 2 — distributed systems

Generate asynchronous/event-driven systems with idempotency, retries, replay, observability and failure isolation.

### Level 3 — enterprise platform engineering

Generate multi-tenant security boundaries, auditability, provider-neutral infrastructure and operational recovery.

### Level 4 — advanced AI platform engineering

Generate model gateways, agent orchestration, tool governance, evaluation, evidence and human approval.

### Level 5 — AMPA-class digital architecture

Generate digital/software/control architecture for:

- Master Orchestrator;
- Specialized Task Agents;
- Digital Thread;
- World Model;
- simulation interfaces;
- process planning;
- quality;
- predictive maintenance;
- robotics integration;
- autonomy governance.

## Reference comparison method

For each challenge:

1. freeze a machine-readable specification;
2. freeze a strong reference architecture/implementation;
3. freeze an acceptance test suite;
4. generate with Software_Factory under a recorded budget;
5. run the same tests;
6. compare outcome dimensions;
7. retain all evidence;
8. classify every remaining gap as engineering defect, integration gap, benchmark gap, or open research question.

## Success categories

- **Bronze** — functionally coherent and verifiably correct on core journeys.
- **Silver** — strong operational characteristics and architecture evidence.
- **Gold** — reference parity across defined dimensions.
- **Research frontier** — demonstrates a measurable result beyond the frozen reference on a specified dimension or establishes a new capability with reproducible evidence.

These labels are descriptive benchmark categories and should never be treated as a universal ranking of all software systems.
