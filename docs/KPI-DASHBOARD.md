# v0.1.0 KPI Dashboard Contract

The factory reports two layers of KPIs.

## Factory layer

- autonomous engineering ratio;
- autonomous repair success;
- regression-free repair;
- evidence coverage;
- task completion and checkpoint continuity;
- import/integration success;
- frontier session artifact turnaround.

## Generated-system layer

- specification realization;
- critical E2E journey success;
- architecture maturity;
- performance;
- scalability;
- resilience/recovery;
- security;
- portability;
- operability;
- reference-system parity;
- novelty/generalization;
- research-frontier evidence.

A release cannot compensate for a hard-gate failure by excelling in another dimension.


## v0.1.0 benchmark measurement rule

A benchmark with no measured evidence is reported as **NOT MEASURED**, not as a pass. The GUI accepts explicit measured benchmark values as JSON so a user can record evidence obtained from independent tests or reference-system comparisons. This prevents default thresholds from being mistaken for empirical performance.
