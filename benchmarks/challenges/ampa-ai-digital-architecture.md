Reference specification: `specs/targets/ampa-ai.toml`

Focus: AMPA-AI digital/software/control architecture including orchestrator, agent swarm, digital thread, world model and safety boundary

## Required benchmark outputs

- requirements graph
- capability graph
- architecture plan

- data/event model
- security and governance model
- deployment profiles
- validation strategy
- failure model
- evidence pack

## Frontier rule

A model-generated solution is not considered frontier-quality merely because it is elaborate. It must be tested against the acceptance framework and compared to a frozen independent reference.
