# Example End-to-End — GUI-first

This example is intentionally written as a GUI walkthrough.

## Scenario

Start with `examples/shipped_solution.zip` and evolve it toward a provider-neutral application platform.

## Walkthrough

1. Open Software_Factory GUI.
2. Workspace → Import as new workspace.
3. Select `examples/shipped_solution.zip` and enter `demo-import`.
4. Inspect `README.md` and `src/app.py` in Files.
5. Update a harmless line and verify Git status.
6. Create a checkpoint.
7. Design → select MOW.
8. Validate specification.
9. Show engineering plan.
10. Generate architecture.
11. Generate scaffold.
12. Verify factory.
13. Generate workspace report.
14. Run the frontier benchmark template or provide measured benchmark values.
15. Create a frontier browser co-work session.
16. Download the context package.
17. Work in the chosen frontier web LLM normally.
18. Download the returned artifact ZIP.
19. Integrate the returned ZIP in Workspace.
20. Verify again.
21. Export the workspace ZIP.

The GUI output area after each action is the authoritative next-step feedback. No routine step requires reproducing the same action with a CLI command.
