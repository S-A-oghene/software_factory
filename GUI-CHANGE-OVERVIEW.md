# v0.1.0 GUI-first change overview

The previous release made the user alternate between terminal commands and browser screens. For an absolute beginner this broke continuity and made a correct workflow feel broken.

This release therefore treats the browser UI as the **operational front end**, not as a demonstration add-on.

The browser UI exposes the normal actions that previously required CLI calls: target validation, planning, architecture generation, scaffolding, shipped-ZIP import, ZIP integration, repository/file CRUD, checkpoints, verification, benchmarking, frontier co-work session creation, and workspace export.

The only routine CLI action left is starting the GUI if automatic startup did not occur.
