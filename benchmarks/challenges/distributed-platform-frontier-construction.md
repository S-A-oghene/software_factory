# Challenge — distributed-platform-frontier-construction

Reference specification: `specs/targets/distributed-platform.toml`

Focus: provider-neutral asynchronous distributed platform with replay, failure isolation, observability and portability

## Required benchmark outputs

- requirements graph
- capability graph
- architecture plan
- interface contracts
- data/event model
- security and governance model
- deployment profiles
- validation strategy
- failure model
- evidence pack

## Frontier rule

A model-generated solution is not considered frontier-quality merely because it is elaborate. It must be tested against the acceptance framework and compared to a frozen independent reference.
