# Challenge — mow-frontier-construction

Reference specification: `specs/targets/mow.toml`

Focus: complete marketing-operations platform with evidence-first workflows, multi-tenancy, AI gateway and human approval

## Required benchmark outputs

- requirements graph
- capability graph
- architecture plan
- interface contracts
- data/event model
- security and governance model
- deployment profiles
- validation strategy
- failure model
- evidence pack

## Frontier rule

A model-generated solution is not considered frontier-quality merely because it is elaborate. It must be tested against the acceptance framework and compared to a frozen independent reference.
