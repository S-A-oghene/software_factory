# Reference Architecture Pack

Use this directory as a place to add a benchmark-specific reference architecture. v0.1.0 intentionally does not pretend that one architecture is universally optimal.

A reference pack should contain:

- architecture diagram;
- requirements mapping;
- interface contracts;
- data/event model;
- security model;
- failure model;
- deployment topology;
- performance measurements;
- test suite;
- version/hash.
